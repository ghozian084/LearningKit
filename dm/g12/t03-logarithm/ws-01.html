1. Basic Concept: The Inverse Function

Addition undoes subtraction. Roots undo powers. A logarithm undoes an exponent! It asks: "10 raised to what power gives me this number?"
Definition: $y = \log_{10} x \iff 10^y = x$
Note: $\log_{10} x$ is often written simply as $\lg x$ or $\log x$.

2. Example Question and Solution

Question: Write $10^4 = 10000$ in logarithmic form, and evaluate $\log_{10}(0.1)$.

Solution: The base is 10. The exponent (the answer to the log) is 4. $\rightarrow \log_{10} 10000 = 4$.
For $\log_{10}(0.1)$, ask "10 to what power is 0.1?". Since $0.1 = \frac{1}{10} = 10^{-1}$, the answer is $-1$.

4. Case: The Domain of Logarithms

Can you find a power of 10 that results in a negative number or zero? Try to solve $10^y = -100$. It is impossible! Any positive number raised to any power will always be strictly greater than zero. Therefore, you cannot take the logarithm of a negative number or zero. The domain is strictly $x > 0$.

1. Basic Concept: General Base Logarithms

We are not restricted to base 10. We can use any positive base $a$ (where $a \neq 1$).
Definition: $y = \log_a x \iff a^y = x$
Special Values: $\log_a a = 1$ (because $a^1 = a$) and $\log_a 1 = 0$ (because $a^0 = 1$).

2. Example Question and Solution

Question: Evaluate $\log_2 16$ and solve $\log_x 25 = 2$.

Solution: Let $\log_2 16 = p$. Convert to exponent: $2^p = 16 \implies 2^4 = 16 \implies p = 4$.
For $\log_x 25 = 2$, convert to exponent: $x^2 = 25 \implies x = 5$ (base must be positive!).

If the unknown is the base itself (e.g., $\log_x 81 = 4$), convert it to exponential form immediately: $x^4 = 81$. Then use roots to solve: $x = \sqrt[4]{81} = 3$. Remember, a logarithm base must always be positive ($x > 0$).

1. Basic Concept: The 3 Laws

Because logarithms are exponents, they follow the index laws! (e.g., adding powers means multiplying bases).
1. Product Law: $\log_a (xy) = \log_a x + \log_a y$
2. Quotient Law: $\log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y$
3. Power Law: $\log_a (x^n) = n \log_a x$

2. Example Question and Solution

Question: Express $2\log 3 + \log 4$ as a single logarithm.

Solution: Use Power Law first: $\log(3^2) + \log 4 = \log 9 + \log 4$.
Use Product Law next: $\log(9 \times 4) = \log 36$.

1. Basic Concept: Equation Strategy & Change of Base

Strategy to solve Log Equations:
1. Use Log Laws to compress multiple logs into ONE single log on each side.
2. Convert to Exponential Form to eliminate the log.
3. Solve for $x$, then CHECK FOR EXTRANEOUS ROOTS (reject if $x$ causes a negative inside a log).
Change of Base: $\log_a b = \frac{\log_c b}{\log_c a}$ (Special case: $\log_a b = \frac{1}{\log_b a}$).

2. Example Question and Solution

Question: Solve $\log_2 x + \log_2 (x-2) = 3$.

Solution: Compress: $\log_2(x(x-2)) = 3$.
Convert: $x(x-2) = 2^3 \implies x^2 - 2x - 8 = 0$. Factorise: $(x-4)(x+2) = 0 \implies x=4$ or $x=-2$. Reject $x=-2$. Answer: $x=4$.

4. Case: Hidden Quadratics via Substitution

Sometimes changing the base creates an equation that looks like a quadratic. If you get $\log_2 x + \frac{1}{\log_2 x} = 2$, use substitution! Let $u = \log_2 x$, so the equation becomes $u + \frac{1}{u} = 2$. Multiply by $u$ to get $u^2 - 2u + 1 = 0$, solve for $u$, then convert back to find $x$.
