Meeting 1: Classifying Data (Part 1)

Main Concept Types of Data

  • Categorical (Qualitative): Non-numerical. Colors, names, opinions.
  • Numerical (Quantitative): Data in number form.
    • Discrete: Counted, exact values (e.g., number of students).
    • Continuous: Measured, can be any decimal value (e.g., height, time, mass).
  • Primary vs Secondary: Did you collect it yourself, or find it online/in a book?

Meeting 2: Organising Data (Part 1)

Main Concept Frequency Tables

  • Tally marks help keep track of raw data. Group them in 5s (||||).
  • Frequency is the total count of each category.
  • Grouped Class Intervals: Used for continuous data or large ranges.
    E.g., $40 \le x < 50$. Intervals must NOT overlap!

Meeting 3: Stem-and-Leaf Diagrams (Part 1)

Main Concept Preserving Raw Data

  • Grouped tables hide the actual numbers. Stem-and-Leaf diagrams group data but keep the original values!
  • Stem: Usually the tens digit. Leaf: Usually the units digit.
  • Data must be ORDERED from smallest to largest.
  • You MUST include a Key (e.g., $1 | 3$ represents 13).

Activity Physical Sorting

Meeting 4: Bar Charts & Pictograms (Part 1)

Main Concept Visual Rules

  • Bar Charts: Must have EQUAL widths and EQUAL gaps between bars (for discrete/categorical data). Label axes clearly!
  • Dual Bar Charts: Used to compare two sets of data side-by-side.
  • Pictograms: Use symbols to represent quantities. A Key is mandatory!

Meeting 5: Pie Charts (Part 1)

Main Concept Proportions of 360°

  • Pie charts show data as a proportion of a whole circle ($360^\circ$).
  • Formula: $\text{Angle} = \left(\frac{\text{Frequency}}{\text{Total Frequency}}\right) \times 360^\circ$
  • Always check that your calculated angles add up exactly to 360° before drawing!
