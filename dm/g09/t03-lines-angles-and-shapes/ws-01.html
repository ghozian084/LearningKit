1. Basic Concept: Transversals on Parallel Lines

When a line (transversal) cuts across two parallel lines, look for these shapes:

  • Corresponding (F-shape): Angles are EQUAL.
  • Alternate Interior (Z-shape): Angles are EQUAL.
  • Co-interior (C-shape): Angles ADD UP to $180^\circ$.
2. Example Question and Solution

Question: If angle $a = 110^\circ$, find the sizes of angles $b$ and $c$.

Solution:
Angle $b$: Vertically opposite to $a$, so $b = 110^\circ$.
Angle $c$: Alternate interior (Z-shape) to $b$, so $c = 110^\circ$.

4. Case: Co-Interior Angles (C-Shape)

If angles are Co-interior (inside the parallel lines, on the SAME side of the transversal), they do not equal each other. They are supplementary. You must set up the equation as: Angle 1 + Angle 2 = 180.

1. Basic Concept: Triangle Properties

Interior Sum: The 3 inside angles always add up to $180^\circ$.
Isosceles Triangle: Has 2 equal sides, which means the 2 base angles are exactly equal.
Exterior Angle Theorem: An outside angle equals the sum of the two opposite inside angles.

2. Example Question and Solution

Question: A triangle has interior angles $50^\circ$, $x$, and $2x$. Find $x$.

Solution: $50 + x + 2x = 180 \implies 3x + 50 = 180 \implies 3x = 130 \implies x = 43.3^\circ$.
