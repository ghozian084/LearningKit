1. Basic Concept: The Inverse Function

Addition undoes subtraction. Roots undo powers. A logarithm undoes an exponent! It asks: "10 raised to what power gives me this number?"
Definition: $y = \log_{10} x \iff 10^y = x$
Note: $\log_{10} x$ is often written simply as $\lg x$ or $\log x$.

2. Example Question and Solution

Question: Write $10^4 = 10000$ in logarithmic form.

Solution: The base is 10. The exponent (the answer to the log) is 4.
$\log_{10} 10000 = 4$.

4. Case: The Domain of Logarithms

Can you find a power of 10 that results in a negative number or zero? Try to solve $10^y = -100$. It is impossible! Any positive number raised to any power will always be strictly greater than zero. Therefore, you cannot take the logarithm of a negative number or zero. The domain is $x > 0$.

1. Basic Concept: General Base Logarithms

We are not restricted to base 10. We can use any positive base $a$ (where $a \neq 1$).
Definition: $y = \log_a x \iff a^y = x$
Special Values: $\log_a a = 1$ (because $a^1 = a$) and $\log_a 1 = 0$ (because $a^0 = 1$).

2. Example Question and Solution

Question: Evaluate $\log_2 16$.

Solution: Let $\log_2 16 = x$. Convert to exponent form: $2^x = 16$. Since $2^4 = 16$, the answer is $4$.

4. Case: Finding the Unknown Base

If the unknown is the base itself (e.g., $\log_x 81 = 4$), convert it to exponential form immediately: $x^4 = 81$. Then use roots to solve: $x = \sqrt[4]{81} = 3$.

Worksheet M3: The Laws of Logarithms
Grade 12 - Pure Math 2 & 3
Name:
Class:
1. Basic Concept: The 3 Laws

Because logarithms are exponents, they follow the index laws! (e.g., adding powers means multiplying bases).
1. Product Law: $\log_a (xy) = \log_a x + \log_a y$
2. Quotient Law: $\log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y$
3. Power Law: $\log_a (x^n) = n \log_a x$

2. Example Question and Solution

Question: Express $2\log 3 + \log 4$ as a single logarithm.

Solution: Use Power Law first: $\log(3^2) + \log 4 = \log 9 + \log 4$.
Use Product Law next: $\log(9 \times 4) = \log 36$.

4. Case: The Deadly Trap

CRITICAL WARNING: $\log(A + B)$ does NOT equal $\log A + \log B$.
There is no law for the log of a sum. If you see $\log_2(x + 5)$, you cannot expand it. Leave it exactly as it is!

Grade 12 - Pure Math 2 & 3

1. Basic Concept: Equation Strategy & Change of Base

Strategy to solve Log Equations:
1. Use Log Laws to compress multiple logs into ONE single log.
2. Convert to Exponential Form to eliminate the log.
3. Solve for $x$, then CHECK FOR EXTRANEOUS ROOTS (reject if $x$ causes a negative inside a log).
Change of Base Formula: $\log_a b = \frac{\log_c b}{\log_c a}$ (Special case: $\log_a b = \frac{1}{\log_b a}$).

2. Example Question and Solution

Question: Solve $\log_2 x + \log_2 (x-2) = 3$.

Solution: Compress: $\log_2(x(x-2)) = 3$.
Convert: $x(x-2) = 2^3 \implies x^2 - 2x - 8 = 0$.
Factorise: $(x-4)(x+2) = 0 \implies x=4$ or $x=-2$. Reject $x=-2$ because we cannot have $\log_2(-2)$. Final answer: $x=4$.

3. Guided Practice: Change of Base

Problem: Solve $\log_3 x + \log_9 x = 6$. The bases don't match!

Step 1: Change $\log_9 x$ into base 3
$\log_9 x = \frac{\log_3 x}{\log_3 9} = \frac{\log_3 x}{\dots\dots} = \frac{1}{2} \log_3 x$.
Step 2: Rewrite equation and solve
$\log_3 x + \frac{1}{2} \log_3 x = 6$
$\frac{3}{2} \log_3 x = 6 \implies \log_3 x = $ $\implies x = 3^{\dots} = $ .
4. Case: Hidden Quadratics

Sometimes changing the base creates an equation that looks like a quadratic. If you get $\log_2 x + \frac{1}{\log_2 x} = 2$, use substitution! Let $u = \log_2 x$, so the equation becomes $u + \frac{1}{u} = 2$. Multiply by $u$ to get $u^2 - 2u + 1 = 0$, solve for $u$, then convert back to find $x$.

Grade 12 - Pure Math 2 & 3
Name:

1. Basic Concept: Bringing the Power Down

To solve equations like $a^x = b$, take the log (or ln) of BOTH sides. Then use the Power Law to bring the $x$ down to the front: $x \log a = \log b$, so $x = \frac{\log b}{\log a}$.
Inequality Rule: If you divide by a negative number, you MUST flip the inequality sign. Remember that $\log(a)$ is negative if $0 < a < 1$ (e.g., $\log 0.5$ is negative!).

2. Example Question and Solution

Question: Solve $3^x = 20$ (to 3 s.f.).

Solution: $\log(3^x) = \log(20) \implies x \log 3 = \log 20 \implies x = \frac{\log 20}{\log 3} = 2.73$.

3. Guided Practice: Complex Exponents

Context: Solve $2^{x+1} = 3^{2x-1}$. The unknown is in powers on both sides!

Step 1: Take logs and bring powers down in brackets
$\log(2^{x+1}) = \log(3^{2x-1})$
$(x+1)\log 2 =$
Step 2: Expand the brackets
$x\log 2 + \log 2 = 2x\log 3 - \log 3$
Step 3: Collect $x$ terms on one side and factorise $x$
$x\log 2 - 2x\log 3 = - \log 3 - \log 2$
$x(\log 2 - 2\log 3) = $
$x = \frac{- \log 3 - \log 2}{\log 2 - 2\log 3} \approx $ (use calculator).
4. Case: The Flipping Sign in Inequalities

Solve $0.5^x < 10$. Take logs: $x \log(0.5) < \log(10)$. To isolate $x$, we must divide by $\log(0.5)$. Because $0.5$ is less than 1, its logarithm is a negative number! Dividing by a negative flips the sign: $x > \frac{\log(10)}{\log(0.5)}$.

1. Basic Concept: Euler's Number

Euler's Number ($e \approx 2.718$): The base of continuous growth and decay in nature.
Natural Logarithm ($\ln$): This is just a logarithm with base $e$. $\log_e x$ is written as $\ln x$.
Because they are inverses: $\ln(e) = 1$, and $\ln(e^x) = x$, and $e^{\ln x} = x$.

2. Example Question and Solution

Question: Solve for $x$: $e^{2x} = 20$.

Solution: Take the natural log ($\ln$) of both sides. $\ln(e^{2x}) = \ln(20)$.
Since $\ln$ and $e$ cancel, $2x = \ln(20) \implies x = \frac{\ln(20)}{2} \approx 1.50$.

4. Case: Solving $\ln$ Equations

To solve an equation that starts with $\ln$, you do the reverse: raise $e$ to the power of both sides! For example, if $\ln(x) = 5$, then $e^{\ln(x)} = e^5 \implies x = e^5$. Just like logs, combine multiple $\ln$ terms using log laws first before raising to $e$.

Grade 12 - Pure Math 2 & 3

1. Basic Concept: Straightening the Curve

We cannot easily analyze exponential curves ($y = Ab^x$). We map them to the straight line equation $Y = mX + C$ by taking logs of both sides.

  • $y = A b^x \implies \log y = (\log b)x + \log A$.
    Plot $\log y$ against $x$. Gradient = $\log b$. Y-int = $\log A$.
  • $y = A x^n \implies \log y = n \log x + \log A$.
    Plot $\log y$ against $\log x$. Gradient = $n$. Y-int = $\log A$.
2. Example Question and Solution

Question: Convert $y = kb^x$ to linear form. State what should be plotted on the Y and X axes.

Solution: $\log y = \log(kb^x) \implies \log y = \log k + x \log b$.
Plot $\log y$ on the vertical axis, and $x$ on the horizontal axis.
