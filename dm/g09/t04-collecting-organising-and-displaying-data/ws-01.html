1. Basic Concept: Types of Data

Categorical (Qualitative): Data in words (e.g., colors, brands, yes/no).
Numerical (Quantitative): Data in numbers.
   $\rightarrow$ Discrete: Counted in exact values (e.g., number of siblings). No fractions!
   $\rightarrow$ Continuous: Measured with instruments (e.g., height, time, mass). Can be decimals.

2. Example Question and Solution

Question: Classify "The number of correct answers on a spelling test."

Solution: Since you count the answers (1, 2, 3...) and cannot get 2.5 correct answers, it is a number. Therefore, it is Numerical Discrete data.

3A. Guided Practice: Designing Health Surveys

Context: Your PjBL group is designing the "Healthy Lifestyles Dashboard". Help classify the survey questions below.

Question A: "What is your favorite type of drink to stay hydrated?"
The answer will be a word (e.g., Water). Therefore, this is data.
Question B: "How many complete glasses of water did you drink yesterday?"
The answer is counted. Therefore, this is Numerical data.
Question C: "What is the exact volume of water in your bottle (in ml)?"
The answer is measured. Therefore, this is Numerical data.
3B. Guided Practice: Primary vs Secondary Data

Primary Data: Data you collected yourself directly (e.g., doing a survey or experiment).
Secondary Data: Data someone else collected that you looked up (e.g., Internet, books, reports).

Scenario 1: You ask 20 classmates about their favorite food.
This is data because you collected it yourself.
Scenario 2: You use a government website to find the population of Jakarta.
This is data because someone else collected it.
4. Case: Tricky Continuous Data

Some data seems discrete but is actually continuous! For example, Age. You might say "I am 14," but you are actually 14 years, 3 months, 2 days, and 5 seconds old. Because age is a measurement of time passing, it is mathematically Continuous data.

1. Basic Concept: Frequency & Two-Way Tables

Tally Marks: Grouped in fives (||||) to easily count raw data.
Frequency: The total number of tally marks for a category.
Class Intervals: Used to group continuous data (e.g., $40 \le x < 50$). Notice they do NOT overlap!
Two-Way Table: Displays data that belongs to two different categories at the same time.

2. Example Question and Solution

4. Case: Overlapping Intervals Warning

When grouping continuous data, you must use inequality signs to prevent overlaps. If your classes are $10 \le h \le 20$ and $20 \le h \le 30$, where does the number $20$ go? It's confusing!
Instead, write: $10 \le h < 20$ and $20 \le h < 30$. Now, exactly 20 goes into the second group.

Grade 9 - Data Handling

1. Basic Concept: Preserving Raw Data

A Stem-and-Leaf Diagram groups data like a frequency table, but you can still see every exact number!
Stem: The first digit(s) (e.g., Tens).
Leaf: The last digit (e.g., Units). Leaves MUST be ordered from smallest to largest.
Key: You must always write a Key to explain the diagram (e.g., Key: $2 | 5$ means 25).

2. Example Question and Solution

Question: Data: $12, 15, 23, 21, 30$. Draw a stem-and-leaf diagram.

1 | 2 5
2 | 1 3      (Notice 21 comes before 23!)
3 | 0
Key: 1 | 2 = 12

4. Case: Back-to-Back Diagrams

To compare two groups (like Boys vs Girls), we use a back-to-back diagram. The Stem goes in the middle. The leaves grow outwards to the left and right. Read carefully: If the stem is 2 and the leaf on the LEFT is 4, the number is 24!

1. Basic Concept: Visual Communication Rules

Bar Charts: Must have EQUAL widths and EQUAL gaps between bars. The y-axis (Frequency) must start at 0 and have an even scale. Label both axes!
Dual Bar Charts: Two bars side-by-side to compare data.
Pictograms: Use symbols. You MUST have a Key (e.g., 1 icon = 4 people). You can draw half an icon to represent 2 people!

2. Example Question and Solution

Question: In a pictogram, the Key says 1 circle = 10 cars. How do you show 25 cars?

Solution: Two full circles = 20 cars. Half a circle = 5 cars. Draw two and a half circles.

4. Case: Misleading Graphs

If a bar chart's vertical axis starts at 50 instead of 0, a bar that is 60 will look twice as tall as a bar that is 55! This is a common trick used in advertising to exaggerate tiny differences. Always start your frequency axis at 0.

1. Basic Concept: Proportions of 360°

Pie Charts show data as a proportion of a whole circle ($360^\circ$).
Formula: $\text{Angle} = \left(\frac{\text{Frequency}}{\text{Total Frequency}}\right) \times 360^\circ$
Line Graphs are used strictly for showing changes over time (e.g., temperature over 12 months).

2. Example Question and Solution

Question: If 10 out of 40 students like swimming, calculate the pie chart angle.

Solution: $\left(\frac{10}{40}\right) \times 360^\circ = \frac{1}{4} \times 360^\circ = 90^\circ$.

4. Case: Working Backwards from Pie Charts

If you are given a pie chart and asked how many people it represents, work backwards! If the Math sector is $90^\circ$, it represents $\frac{90}{360} = \frac{1}{4}$ of the total people. If the total surveyed was 200, then Math = $\frac{1}{4} \times 200 = 50$ people.
